# Mini Design System · Yasmani Viñamagua

Generado 2026-10-21 por `/yas-figma mini` (alcance **mini**: solo fundamentos). Fuente: manual de identidad v1.1.

- Entregable visual: `design-system.html` (abrir con doble clic).
- Tokens: `.yas/tokens/tokens.json` · contraste: `.yas/tokens/contraste.md`.

## Orden de implementación en Figma

1. [ ] Crear las 9 páginas de `nomenclatura.md` (el plan gratuito de Figma solo admite 3 por archivo).
2. [ ] Crear las colecciones de `variables.md`: Primitivas → Semánticas (Light/Dark) → Espaciado y forma → Tipografía.
3. [ ] Crear los estilos de texto, efecto y cuadrícula de `estilos.md`.
4. [ ] Instalar las fuentes Nunito y Manrope (Google Fonts, SIL OFL; verificar licencia para uso comercial).
5. [ ] Montar cada página con muestras enlazadas a variables (sin valores fijos).
6. [ ] Brand assets: importar los SVG de `logo/` (versiones del manual §4).
7. [ ] Cover: nombre, versión 1.1, fecha, estado.

Con el MCP de Figma disponible y con cuota, `/yas-figma push` hace los pasos 1 a 6.
