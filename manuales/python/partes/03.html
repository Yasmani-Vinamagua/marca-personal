Funciones

Definición y retorno de valores

Una función es un bloque de código con nombre que puede ejecutarse varias veces. Se define con la palabra clave def, y la instrucción return finaliza su ejecución y, opcionalmente, devuelve un valor.

def imprimir_mensaje():
    print("mensaje especial: ")
    print("estoy aprendiendo a usar funciones")


def sumar(a, b):
    return a + b


resultado = sumar(3, 4)
print(resultado)
>> 7

Argumentos de cantidad variable: *args y **kwargs

Cuando no se conoce de antemano el número de argumentos que se pasarán a una función se emplean dos sintaxis especiales. El nombre args o kwargs no es obligatorio, pero se recomienda como buena práctica; cualquier nombre precedido por * o ** cumple la misma función.

  • *args agrupa en una tupla los argumentos posicionales adicionales, después de los obligatorios.
  • **kwargs (keyword arguments) agrupa en un diccionario los argumentos con nombre, que identifican al argumento por su nombre y no por su posición.
def mi_funcion(arg_1, arg_2, *args):
    print(arg_1, arg_2, args)

mi_funcion("ejemplo", 25, 40, 75, 10)
>> ejemplo 25 (40, 75, 10)


def atributos_persona(**kwargs):
    print(kwargs)

atributos_persona(ojos="azules", pelo="corto")
>> {'ojos': 'azules', 'pelo': 'corto'}

Funciones anónimas: lambda

Una función lambda es una función sin nombre, limitada a una sola expresión. Su estructura es lambda argumentos: expresión.

doble = lambda x: x * 2
print(doble(4))
>> 8

Alcance de las variables (scope)

El alcance determina desde dónde puede utilizarse una variable. Una variable local existe solo dentro del bloque en que se define; una variable global está disponible en todas las funciones del módulo. Pueden coexistir una variable local y una global con el mismo nombre y valores distintos.

Funciones anidadas y clausuras

Una función anidada (nested function) es una función definida dentro de otra. Una clausura (closure) ocurre cuando una función interna recuerda una variable de un ámbito superior aunque ese ámbito ya no exista. Para que exista una clausura deben cumplirse tres condiciones:

  1. Debe haber una función anidada.
  2. La función anidada debe hacer referencia a un valor de un ámbito superior.
  3. La función que envuelve a la anidada debe retornarla.
def crear_multiplicador(factor):
    def multiplicar(numero):
        return numero * factor   # recuerda "factor"
    return multiplicar


por_tres = crear_multiplicador(3)
print(por_tres(5))
>> 15

Las clausuras aparecen con frecuencia en clases cortas y en el uso de decoradores.

Síntesis

  • def define una función y return devuelve un valor.
  • *args recibe argumentos posicionales como tupla; **kwargs, argumentos con nombre como diccionario.
  • Una clausura es una función interna que conserva variables del ámbito que la contiene.

Decoradores, iteradores y generadores

Decoradores

Un decorador es una función que recibe otra función como parámetro, le añade comportamiento y retorna una función diferente, sin modificar el código interno de la original. Se emplea para agregar comprobaciones (por ejemplo, permisos), medir el tiempo de ejecución, registrar eventos y reutilizar código. Se aplica escribiendo @nombre_del_decorador encima de la función decorada.

def decorar_saludo(funcion):

    def otra_funcion(palabra):
        print("hola")
        funcion(palabra)
        print("adios")

    return otra_funcion


@decorar_saludo
def minuscula(texto):
    print(texto.lower())


def mayuscula(texto):
    print(texto.upper())


mayuscula("PytHon")
minuscula("PytHon")
>> PYTHON
>> hola
>> python
>> adios
Nota

La línea @decorar_saludo equivale a ejecutar minuscula = decorar_saludo(minuscula). Si la función original recibe parámetros, la función interna del decorador debe aceptar *args y **kwargs para transmitirlos.

Iterables e iteradores

Un iterable es todo objeto que puede recorrerse en un ciclo, como una lista o una cadena. Un iterador produce sus elementos de uno en uno; ahorra recursos porque puede representar secuencias y progresiones matemáticas ocupando poca memoria.

Generadores

Un generador es una función especial que no devuelve todos los valores a la vez, sino que los genera uno por uno cuando se le piden. Utiliza la palabra clave yield en lugar de return: al encontrarla, pausa su ejecución y devuelve el valor; cuando se reanuda, continúa justo donde se quedó. Conserva un estado, ofrece las ventajas de un iterador con una sintaxis más sencilla y es útil para leer archivos línea por línea, procesar datos masivos o crear flujos infinitos.

def mi_generador():
    x = 1
    yield x

    x += 1
    yield x

    x += 1
    yield x


g = mi_generador()

print(g)
print(next(g))
print(next(g))
print("Hola mundo")
print(next(g))
>> <generator object mi_generador at 0x000001C7FF054B80>
>> 1
>> 2
>> Hola mundo
>> 3

La dirección de memoria que aparece en la primera línea varía en cada ejecución. Las expresiones generadoras siguen la sintaxis de la comprensión de listas, pero con paréntesis: mientras la comprensión de listas almacena todos los elementos en memoria, la expresión generadora los entrega uno por uno.

cuadrados_lista = [n**2 for n in range(1000)]   # todos los elementos en memoria
cuadrados_gen = (n**2 for n in range(1000))     # un elemento a la vez

Síntesis

  • Un decorador envuelve una función para ampliar su comportamiento sin alterar su código.
  • Un generador, definido con yield, produce valores bajo demanda y ahorra memoria.
  • La expresión generadora es la versión perezosa de la comprensión de listas.

Programación orientada a objetos

Clases, objetos, atributos y métodos

Una clase es una plantilla que define las propiedades (atributos) y las acciones (métodos) de los objetos creados a partir de ella. Es un concepto fundamental de la programación orientada a objetos porque permite organizar el código de forma modular y reutilizable. Un objeto (o instancia) es una entidad concreta con sus propios datos y comportamientos, creada desde una clase.

class Perro:                      # clase

    def __init__(self, raza):     # método especial que asigna el atributo "raza"
        self.raza = raza

    def ladrar(self):             # método
        print(f"{self.raza} ha ladrado")


mi_perro = Perro("Chihuahua")     # objeto con el atributo "Chihuahua"
mi_perro.ladrar()
>> Chihuahua ha ladrado

Atributos

Los atributos son las características o datos que pertenecen a un objeto o a una clase. Los atributos de instancia son propios de cada objeto y se definen con self (por ejemplo, la raza, el color o el nombre de un perro). Los atributos de clase son comunes a todos los objetos y se definen directamente dentro de la clase.

Métodos

Los métodos son funciones definidas dentro de una clase que permiten a los objetos realizar acciones con sus atributos. Existen tres tipos.

Tabla 13Tipos de Métodos en una Clase

TipoDecoradorPrimer parámetroAcceso y uso
De instancia—selfOperan sobre un objeto y acceden a sus atributos de instancia. Son los más comunes.
De clase@classmethodclsSe relacionan con la clase, no con las instancias; acceden a los atributos de clase.
Estático@staticmethod—No acceden a atributos de clase ni de instancia; agrupan funciones relacionadas con la clase.

Nota. Adaptado de las notas del autor.

class Pajaro:

    alas = True                       # atributo de clase

    def __init__(self, color, especie):
        self.color = color
        self.especie = especie

    def caracteristicas(self):        # método de instancia
        print(f"Piolin es un {self.especie} de color {self.color}")

    def volar(self, metros):
        print(f"El pajaro vuela {metros} metros")
        self.especie = "colibrí"      # se pueden modificar los atributos del objeto
        print(f"Ahora el pajaro es un {self.especie}")
        self.caracteristicas()        # se puede llamar a otros métodos de instancia

    @classmethod
    def poner_huevos(cls, cantidad):  # método de clase
        print(f"Puso {cantidad} huevos")
        cls.alas = True               # se puede modificar un atributo de clase
        print(Pajaro.alas)

    @staticmethod
    def mirar():                      # método estático
        print("El pajaro es ciego")


piolin = Pajaro("amarillo", "canario")   # objeto (instancia)
piolin.volar(5)
piolin.alas = False                      # modifica el atributo solo en este objeto
print(piolin.alas)
Pajaro.poner_huevos(3)                   # no necesita una instancia
Pajaro.mirar()
>> El pajaro vuela 5 metros
>> Ahora el pajaro es un colibrí
>> Piolin es un colibrí de color amarillo
>> False
>> Puso 3 huevos
>> True
>> El pajaro es ciego
Importante

La instrucción piolin.alas = False crea un atributo de instancia que oculta al atributo de clase solo para ese objeto; el atributo de la clase Pajaro.alas no cambia, lo cual explica que poner_huevos() imprima True.

Herencia

La herencia permite que una clase obtenga los atributos y métodos de otra. La clase original se denomina clase padre o superclase, y la que hereda, clase hija o subclase. La subclase dispone automáticamente de todo lo definido en la superclase y puede agregar elementos propios.

class Animal:
    def __init__(self, edad, color):
        self.edad = edad
        self.color = color

    def nacer(self):
        print("Este animal ha nacido")
        print(f"Tiene {self.edad} años y es de color {self.color}")


class Pajaro(Animal):
    pass


piolin = Pajaro(2, "amarillo")
piolin.nacer()

Herencia extendida

La subclase puede además añadir atributos o métodos propios, sobrescribir un método heredado para que funcione de otra manera y llamar al método original mediante super() cuando necesita conservar parte del comportamiento de la superclase.

class Animal:
    def __init__(self, edad, color):
        self.edad = edad
        self.color = color

    def nacer(self):
        print("Este animal ha nacido")

    def hablar(self):
        print("Este animal emite un sonido")


class Pajaro(Animal):
    def __init__(self, edad, color, vuelo_metros):
        super().__init__(edad, color)       # reutiliza el constructor de Animal
        self.vuelo_metros = vuelo_metros

    def hablar(self):                       # sobrescribe el método heredado
        print(f"{self.color}")

    def volar(self):
        print(f"El pajaro vuela {self.vuelo_metros} metros")


class Aguila(Pajaro):
    pass


mi_aguila = Aguila(30, "marrón", 5)
mi_aguila.volar()
>> El pajaro vuela 5 metros

Polimorfismo

El polimorfismo significa que diferentes clases pueden usar el mismo nombre de método, pero cada una lo implementa a su manera. Así, un mismo código puede operar sobre objetos de clases distintas.

class Vaca:
    def __init__(self, nombre):
        self.nombre = nombre

    def hablar(self):
        print(self.nombre + " dice muuuu")


class Oveja:
    def __init__(self, nombre):
        self.nombre = nombre

    def hablar(self):
        print(self.nombre + " dice meeeeee")


animales = [Vaca("Aurora"), Oveja("Nube")]

for animal in animales:
    animal.hablar()
>> Aurora dice muuuu
>> Nube dice meeeeee

Métodos especiales

Los métodos especiales (también llamados métodos «mágicos» o magic methods) son funciones cuyo nombre empieza y termina con dos guiones bajos, como __nombre__. Otorgan comportamientos particulares a los objetos y Python los invoca de forma automática en ciertas situaciones.

Tabla 14Métodos Especiales Empleados en los Ejemplos

MétodoSe invoca cuando…
__init__se crea un objeto; inicializa sus atributos.
__str__se llama a str(objeto) o print(objeto); devuelve su representación en texto.
__len__se llama a len(objeto).
__del__el objeto se elimina, por ejemplo con del objeto.

Nota. Elaboración propia a partir de las notas del autor.

class CD:

    def __init__(self, autor, titulo, canciones):
        self.autor = autor
        self.titulo = titulo
        self.canciones = canciones

    def __str__(self):
        return f"Album: {self.titulo} de {self.autor}"

    def __len__(self):
        return self.canciones

    def __del__(self):
        print(f"Se ha eliminado la canción {self.titulo}")


mi_cd = CD("Pink Floyd", "The Wall", 24)

print(str(mi_cd))
print(len(mi_cd))
del mi_cd
>> Album: The Wall de Pink Floyd
>> 24
>> Se ha eliminado la canción The Wall

Pilares de la programación orientada a objetos

El curso de referencia presenta la programación orientada a objetos como un modo de programación basado en seis pilares. Dos de ellos, la herencia y el polimorfismo, se desarrollaron en este capítulo. Los cuatro restantes tienen un carácter más conceptual:

  • Cohesión.
  • Acoplamiento.
  • Abstracción.
  • Encapsulamiento.

Síntesis

  • Una clase es una plantilla; un objeto es una instancia con datos propios.
  • Los métodos pueden ser de instancia (self), de clase (cls) o estáticos.
  • La herencia reutiliza código y super() permite aprovechar el comportamiento de la superclase.
  • El polimorfismo permite que clases distintas respondan al mismo método de maneras diferentes.
