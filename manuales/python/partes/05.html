Videojuego con Pygame: Invasión Espacial

Este proyecto construye, paso a paso, un videojuego en dos dimensiones con la biblioteca pygame. Cada subsección muestra únicamente el código nuevo o modificado respecto del paso anterior; el programa completo se incluye en el anexo A. Los archivos de imagen y sonido (logo_color.png, mouse.png, veneno.png, bala.png, fondo.png, MusicaFondo.mp3, disparo.mp3 y Golpe.mp3) deben estar en la misma carpeta que el programa.

Paso 1. Crear la pantalla

Se importa el paquete, se inicializa y se crea una ventana de 800 × 600 píxeles. El bucle del juego se mantiene mientras la variable se_ejecuta sea verdadera y la ventana se cierra al hacer clic en la «X».

import pygame

pygame.init()                                   # inicializa Pygame
pantalla = pygame.display.set_mode((800, 600))  # pantalla de 800 px x 600 px

se_ejecuta = True

while se_ejecuta:                               # bucle del juego
    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:          # clic en la X de la ventana
            se_ejecuta = False

Paso 4. Mover al personaje

Una variable de cambio guarda la velocidad horizontal. Al presionar una flecha se asigna un valor positivo o negativo, y al soltarla vuelve a cero. Además, se limita la posición para que la nave no salga de la pantalla: el máximo es 800 − 64, donde 64 corresponde al ancho de la imagen.

jugador_x_cambio = 0

def jugador(x, y):
    pantalla.blit(img_jugador, (x, y))

# dentro del bucle, en la revisión de eventos:
    if evento.type == pygame.KEYDOWN:
        if evento.key == pygame.K_LEFT:
            jugador_x_cambio = -0.1
        elif evento.key == pygame.K_RIGHT:
            jugador_x_cambio = 0.1

    if evento.type == pygame.KEYUP:
        if evento.key == pygame.K_LEFT or evento.key == pygame.K_RIGHT:
            jugador_x_cambio = 0

# después de los eventos:
    jugador_x += jugador_x_cambio

    if jugador_x <= 0:
        jugador_x = 0
    elif jugador_x >= 736:
        jugador_x = 736

    jugador(jugador_x, jugador_y)

Paso 9. Detectar colisiones

Se calcula la distancia euclidiana entre la bala y el enemigo: si es menor que 27 píxeles, se considera que hubo colisión. En ese caso la bala vuelve a su posición inicial, aumenta el puntaje y el enemigo reaparece en un lugar aleatorio.

import math

puntaje = 0

def colision(x_1, y_1, x_2, y_2):
    operacion1 = math.pow((x_2 - x_1), 2)
    operacion2 = math.pow((y_2 - y_1), 2)
    distancia = math.sqrt(operacion1 + operacion2)
    if distancia < 27:
        return True
    else:
        return False

# en el bucle:
    hay_colision = colision(enemigo_x, enemigo_y, bala_x, bala_y)
    if hay_colision:
        bala_y = 500
        bala_visible = False
        puntaje += 1
        enemigo_x = random.randint(0, 736)
        enemigo_y = random.randint(50, 200)

Para generar varios enemigos, cada atributo (imagen, posición y velocidades) se guarda en una lista, y un bucle for los inicializa y los actualiza.

# en el bucle, el movimiento y las colisiones se aplican a cada enemigo:
    for e in range(cantidad_enemigos):

        if enemigo_x[e] <= 0:
            enemigo_x_cambio[e] = 0.5

            enemigo_y[e] = random.randint(50, 200)

        enemigo(enemigo_x[e], enemigo_y[e], e)

Nota

Este ejemplo desplaza los objetos una cantidad fija en cada vuelta del bucle, por lo que la velocidad aparente depende de la rapidez del equipo. En proyectos de mayor tamaño conviene limitar el número de cuadros por segundo del bucle.

Interfaz gráfica con Tkinter

tkinter es la interfaz estándar de Python para el conjunto de herramientas gráficas Tcl/Tk; es un módulo opcional que viene incluido en la mayoría de las instalaciones (Python Software Foundation, s. f.-d). Una aplicación se construye creando una ventana, agregando widgets (paneles, etiquetas, cuadros de texto, botones) y entregando el control a un bucle de eventos con mainloop(), que procesa las acciones del usuario hasta que se cierran todas las ventanas.

Configuración de la ventana

from tkinter import *

aplicacion = Tk()                                   # inicia tkinter

aplicacion.geometry("1020x630+0+0")                 # tamaño 1020x630, ubicada en (0, 0)
aplicacion.resizable(0, 0)                          # impide redimensionar en X y en Y
aplicacion.title("Aplicación Yasmani - Restaurante")
aplicacion.config(bg="pink")                        # color de fondo

aplicacion.mainloop()                               # evita que la ventana se cierre

Ejemplo: sistema de facturación de un restaurante

El ejemplo integra los elementos habituales de una aplicación de escritorio: paneles organizados con pack() y grid(), casillas de verificación (Checkbutton) que habilitan cuadros de entrada (Entry), variables enlazadas a los widgets (StringVar, IntVar), una calculadora, un área de recibo (Text) y botones que ejecutan funciones: calcular el total, generar el recibo, guardarlo en un archivo y reiniciar el formulario.

Importante

La calculadora del ejemplo evalúa la operación con la función eval(), que ejecuta cualquier expresión de Python. Es aceptable aquí porque el texto proviene solo de botones numéricos, pero no debe usarse con texto introducido libremente por el usuario.

def total():
    sub_total_comida = 0

Asistente de voz

Un asistente virtual por voz se construye combinando varios módulos externos: pyttsx3 (síntesis de voz), speech_recognition (reconocimiento de voz desde el micrófono), pywhatkit (automatización de WhatsApp y YouTube), pyjokes (chistes), wikipedia (consulta de información), además de webbrowser y datetime, de la biblioteca estándar. El asistente de este ejemplo responde con voz, escucha comandos por el micrófono, abre sitios web, informa el día y la hora, busca en Wikipedia e internet, reproduce videos de YouTube y cuenta chistes.

pip install pyttsx3 SpeechRecognition pywhatkit pyjokes wikipedia pyaudio
Importante

El reconocimiento de voz con recognize_google() requiere conexión a internet, y la lista de voces disponibles depende del sistema operativo. Los identificadores de voz del ejemplo corresponden a voces de Windows, que se muestran con el fragmento comentado del código. El paquete PyAudio solo es necesario para usar el micrófono (Python Package Index, s. f.).

import pyttsx3
import speech_recognition as sr
import pywhatkit
import pyjokes
import webbrowser
from datetime import datetime
import wikipedia


# Escuchar el micrófono y devolver el audio como texto
def transformar_audio_en_texto():

    # almacenar el reconocedor en una variable
    r = sr.Recognizer()

    # configurar el micrófono
    with sr.Microphone() as origen:

        # tiempo de espera
        r.pause_threshold = 0.8

        # informar que comenzó la grabación
        print("ya puedes hablar")

        # guardar lo que escuche como audio
        audio = r.listen(origen)

        try:
            # buscar en Google
            pedido = r.recognize_google(audio, language="es-ec")

            # prueba de que pudo ingresar
            print("Dijiste: " + pedido)

            # devolver pedido
            return pedido

        # en caso de que no comprenda el audio
        except sr.UnknownValueError:
            print("Ups, no entendí")
            return "sigo esperando"

        # en caso de no resolver el pedido
        except sr.RequestError:
            print("Ups, no hay servicio")
            return "sigo esperando"

        # error inesperado
        except:
            print("Ups, algo ha salido mal")
            return "sigo esperando"

# Informar el día de la semana
def pedir_dia():

    # crear datos de hoy
    dia = datetime.today()

    # día de la semana (0 = lunes)
    dia_semana = dia.weekday()

    hora = datetime.now()

# Saludo inicial
def saludo_inicial():
    hora = datetime.now()
    if hora.hour < 6 or hora.hour > 20:
        momento = "Buenas noches"
    elif 6 <= hora.hour < 13:
        momento = "Buen día"
    else:
        momento = "Buenas tardes"

    hablar(f"Hola Yasmani, {momento}, soy Helena, tu asistente personal. "
           "Por favor, dime en qué te puedo ayudar")


# Función central del asistente
def pedir_cosas():

    # activar el saludo inicial
    saludo_inicial()

    # variable de corte
    comenzar = True

    # bucle central
    while comenzar:

        # activar el micrófono y guardar el pedido en un string
        pedido = transformar_audio_en_texto().lower()

        if "abrir youtube" in pedido:
            hablar("Con gusto, estoy abriendo YouTube")
            webbrowser.open("https://www.youtube.com")
            continue
        elif "abrir navegador" in pedido:
            hablar("Claro, estoy en eso")
            webbrowser.open("https://www.google.com")
            continue
        elif "qué día es hoy" in pedido:
            pedir_dia()
            continue
        elif "qué hora es" in pedido:
            pedir_hora()
            continue
        elif "busca en wikipedia" in pedido:
            hablar("Buscando eso en wikipedia")
            pedido = pedido.replace("busca en wikipedia", "")
            wikipedia.set_lang("es")
            resultado = wikipedia.summary(pedido, sentences=1)
            hablar(f"Wikipedia dice lo siguiente: {resultado}")
            continue
        elif "busca en internet" in pedido:
            hablar("Lo estoy buscando")
            pedido = pedido.replace("busca en internet", "")
            pywhatkit.search(pedido)
            hablar("Esto es lo que he encontrado")
            continue

            pywhatkit.playonyt(pedido)
            continue
        elif "chiste" in pedido:
            hablar(pyjokes.get_joke("es"))

Reconocimiento facial

El reconocimiento facial se apoya en cuatro componentes: opencv-python captura la imagen o el video; face-recognition (que utiliza dlib) detecta y reconoce rostros; numpy procesa los datos de imagen como matrices, y cmake se usa durante la instalación para compilar los componentes necesarios.

pip install cmake
pip install opencv-python face-recognition numpy

El ejemplo se desarrolla en ocho etapas: cargar las imágenes, comparar caras, medir la diferencia (distancia), mostrar la distancia, crear una base de datos, encontrar coincidencias, mostrar coincidencias y registrar la asistencia.

Comparación de dos fotografías

La función compare_faces() devuelve si dos rostros coinciden. Por defecto la tolerancia es de 0,6: cuanto más cercana a cero, más exacta debe ser la coincidencia. La función face_distance() mide la diferencia numérica entre los rostros.

import cv2
import face_recognition as fr

# cargar imágenes
foto_control = fr.load_image_file("FotoA.jpg")
foto_prueba = fr.load_image_file("FotoC.jpg")

# pasar las imágenes a RGB
foto_control = cv2.cvtColor(foto_control, cv2.COLOR_BGR2RGB)
foto_prueba = cv2.cvtColor(foto_prueba, cv2.COLOR_BGR2RGB)

# localizar y codificar la cara de control
lugar_cara_A = fr.face_locations(foto_control)[0]
cara_codificada_A = fr.face_encodings(foto_control)[0]

# localizar y codificar la cara de prueba
lugar_cara_B = fr.face_locations(foto_prueba)[0]
cara_codificada_B = fr.face_encodings(foto_prueba)[0]

# mostrar rectángulos
cv2.rectangle(foto_control, (lugar_cara_A[3], lugar_cara_A[0]),
              (lugar_cara_A[1], lugar_cara_A[2]), (0, 255, 0), 2)
cv2.rectangle(foto_prueba, (lugar_cara_B[3], lugar_cara_B[0]),
              (lugar_cara_B[1], lugar_cara_B[2]), (0, 255, 0), 2)

# realizar la comparación
resultado = fr.compare_faces([cara_codificada_A], cara_codificada_B)

# medir la distancia
distancia = fr.face_distance([cara_codificada_A], cara_codificada_B)

# mostrar el resultado
cv2.putText(foto_prueba, f"{resultado}{distancia.round(2)}", (50, 50),
            cv2.FONT_HERSHEY_DUPLEX, 1, (0, 255, 0), 2)

# mostrar las imágenes
cv2.imshow("Foto Control", foto_control)
cv2.imshow("Foto Prueba", foto_prueba)

# mantener el programa abierto
cv2.waitKey(0)

Registro de asistencia con cámara web

El segundo programa construye una base de datos a partir de las fotografías de una carpeta (el nombre de cada archivo corresponde al nombre del empleado), toma una imagen de la cámara web, busca la mejor coincidencia y, si la distancia es menor o igual a 0,6, dibuja el nombre sobre el rostro y registra la hora de ingreso en el archivo registro.csv.

import cv2
import face_recognition as fr
import os
import numpy
from datetime import datetime

# crear la base de datos
ruta = "Empleados"
mis_imagenes = []
nombres_empleados = []
lista_empleados = os.listdir(ruta)

for nombre in lista_empleados:
    imagen_actual = cv2.imread(f"{ruta}/{nombre}")
    mis_imagenes.append(imagen_actual)
    nombres_empleados.append(os.path.splitext(nombre)[0])

print(nombres_empleados)


# codificar imágenes
def codificar(imagenes):

    # crear una lista nueva
    lista_codificada = []

    # pasar todas las imágenes a RGB
    for imagen in imagenes:
        imagen = cv2.cvtColor(imagen, cv2.COLOR_BGR2RGB)

        # codificar
        codificado = fr.face_encodings(imagen)[0]

        # agregar a la lista
        lista_codificada.append(codificado)

    # devolver la lista codificada
    return lista_codificada

Sitio web con Django

Django es un framework web de alto nivel para Python que permite desarrollar aplicaciones web de forma rápida, segura y escalable. El procedimiento inicial es el siguiente.

  1. Crear y activar un entorno virtual (ver el capítulo 11): python -m venv venv.
  2. Instalar Django en el entorno: pip install django. Esto permite crear aplicaciones web con funcionalidades completas.
  3. Crear un directorio para el proyecto: mkdir src y cd src. El nombre src es una abreviatura habitual de «source» (código fuente).
  4. Crear el proyecto: django-admin startproject nombre_proyecto, y luego ingresar a la carpeta con cd nombre_proyecto.
  5. Iniciar el servidor de desarrollo: python manage.py runserver. El sitio queda disponible en http://127.0.0.1:8000/; aún no tiene contenido, pero el sistema funciona.
  6. Aplicar las migraciones iniciales: python manage.py migrate. Las aplicaciones internas de Django (auth, admin, sessions) requieren tablas en la base de datos; este comando las crea.
  7. Crear un usuario administrador: python manage.py createsuperuser. Ese usuario puede iniciar sesión en el panel de administración (/admin) para gestionar usuarios y modelos.
Para ampliar

La documentación oficial advierte que el servidor de desarrollo, ligero y escrito íntegramente en Python, está pensado solo para el desarrollo y no debe emplearse en un entorno de producción (Django Software Foundation, s. f.).
