Fundamentos del lenguaje

Estructura básica de un programa

Un programa en Python es un archivo de texto con extensión .py cuyas instrucciones se ejecutan de arriba hacia abajo. Es recomendable encapsular la lógica principal en una función y ejecutarla únicamente cuando el archivo se lanza de forma directa, no cuando se importa desde otro:

def run():
    palabra = input("Escribe una palabra: ")
    print(palabra)


if __name__ == "__main__":
    run()

Python delimita los bloques mediante la indentación, que es obligatoria. La guía de estilo oficial recomienda cuatro espacios por nivel, líneas de un máximo de 79 caracteres, nombres de funciones y variables en minúscula con guiones bajos, nombres de clases en formato CapWords y constantes en mayúsculas (van Rossum et al., 2001). Por esa razón, un valor que no cambia se nombra en mayúsculas:

LIMITE = 1000
Para ampliar

La guía de estilo se denomina PEP 8 (Python Enhancement Proposal 8) y la documentación oficial del lenguaje se encuentra en docs.python.org/3 (Python Software Foundation, s. f.-c). Al ejecutar import this en la consola se muestra el «Zen de Python», un conjunto de principios de diseño del lenguaje.

Entrada de datos con input

La función input() permite que el programa reciba datos del usuario durante su ejecución. Muestra un mensaje y devuelve lo escrito.

nombre = input("Dime tu nombre: ")
print("Tu nombre es " + nombre)
>> Dime tu nombre: Yasmani
>> Tu nombre es Yasmani

Todo valor devuelto por input() es una cadena de texto, incluso si el usuario escribe números. Cuando se requiere un número, el dato debe convertirse:

edad = int(input("¿Cuántos años tienes? "))
altura = float(input("¿Cuál es tu altura en metros? "))

Para recibir varios valores en una misma línea se combina input() con el método split():

x, y = input("Introduce dos números separados por espacio: ").split()
x = int(x)
y = int(y)
print("La suma es:", x + y)

La función print() muestra información en la consola. Las cadenas pueden concatenarse con el operador + e incluir secuencias de escape, que son combinaciones que comienzan con una barra invertida.

Existen tres formas de combinar texto y variables. La concatenación simple une cadenas; el método format() sustituye marcadores {}; y las cadenas literales formateadas (f-strings), precedidas por la letra f, incorporan expresiones directamente entre llaves.

print("hola" + " " + "mundo")
>> hola mundo

print("Mi auto es {} y de matrícula {}".format(color_auto, matricula))

print(f"Mi auto es {color_auto} y de matrícula {matricula}")
Para ampliar

Las f-strings admiten además un especificador de formato después de dos puntos; por ejemplo, f"{math.pi:.3f}" muestra el número pi con tres decimales (Python Software Foundation, s. f.-b).

Síntesis

  • Un programa se organiza en funciones, y if __name__ == "__main__" controla su ejecución directa.

Cadenas de texto

Indexado, búsqueda y porciones

Una cadena (string) es una secuencia de caracteres. Cada carácter ocupa una posición numerada a partir de cero, y también puede numerarse desde el final con números negativos. Las cadenas son inmutables: los métodos que las «modifican» devuelven una cadena nueva.

nombre = "Yasmani"
print(nombre[0])       # primer carácter
print(len(nombre))     # número de caracteres

El método index() localiza un carácter o fragmento y devuelve su posición; admite posiciones de inicio y fin de búsqueda. El método rindex() busca de derecha a izquierda.

mi_texto = "Esta es una prueba"
print(mi_texto.index("n"))         # 9
print(mi_texto.index("a", 5))      # 10
print(mi_texto.index("a", 5, 16))  # 10
print(mi_texto.rindex("a"))        # 17

El corte (slicing) extrae porciones mediante la sintaxis cadena[inicio:fin:paso]. El índice final no se incluye, y un paso negativo recorre la cadena en sentido inverso.

Métodos de transformación

Dado que las cadenas son inmutables, los métodos de transformación no actúan sobre el objeto original, sino que devuelven uno nuevo.

Tabla 6Métodos de Transformación de Cadenas

MétodoDescripciónEjemplo
capitalize()Primera letra en mayúscula."hola mundo".capitalize() → 'Hola mundo'
upper(), lower()Todo en mayúsculas o en minúsculas."Hola Mundo!".upper() → 'HOLA MUNDO!'
swapcase()Invierte mayúsculas y minúsculas."Hola Mundo!".swapcase() → 'hOLA mUNDO!'
replace()Reemplaza un fragmento por otro."Hola mundo".replace("mundo", "world") → 'Hola world'
strip(), lstrip(), rstrip()Eliminan espacios al inicio y al final, solo al inicio o solo al final." Hola mundo! ".strip() → 'Hola mundo!'

Separación y unión

Tabla 7Métodos de Separación y Unión de Cadenas

MétodoDescripciónEjemplo
split()Divide la cadena por un separador (por defecto, espacios); un segundo argumento limita las divisiones."Hola mundo!\nHello world!".split() → ['Hola', 'mundo!', 'Hello', 'world!']
splitlines()Divide la cadena en cada salto de línea."Hola mundo!\nHello world!".splitlines() → ['Hola mundo!', 'Hello world!']
partition()Devuelve una tupla con lo anterior a la primera aparición del separador, el separador y lo posterior."Hola mundo. Hello world!".partition(" ") → ('Hola', ' ', 'mundo. Hello world!')
rpartition()Igual que partition(), pero desde el final."Hola mundo. Hello world!".rpartition(" ") → ('Hola mundo. Hello', ' ', 'world!')
join()Une los elementos de una lista usando la cadena como separador.", ".join(["C", "C++", "Python", "Java"]) → 'C, C++, Python, Java'

Síntesis

  • Las cadenas se indexan desde cero (o desde el final con números negativos) y se cortan con [inicio:fin:paso].
  • Son inmutables: cada método de transformación devuelve una cadena nueva.
  • find() devuelve -1 si no encuentra el fragmento, mientras que index() lanza un error.
