Estructuras de datos

Panorama de las colecciones

Python ofrece cuatro colecciones integradas que almacenan varios valores en una sola variable: listas, tuplas, diccionarios y conjuntos. Se diferencian por tres propiedades: si pueden modificarse después de crearse (mutabilidad), si conservan un orden y si admiten elementos repetidos.

Listas

Una lista es una secuencia ordenada y mutable de objetos de cualquier tipo: cadenas, números, booleanos o incluso otras listas.

lista_1 = ["C", "C++", "Python", "Java"]

print(lista_1[1:3])      # indexado con [inicio:fin:paso]
>> ['C++', 'Python']

print(len(lista_1))      # número de elementos
>> 4

print(lista_1 + lista_2) # concatenación
>> ['C', 'C++', 'Python', 'Java', 'PHP', 'SQL', 'Visual Basic']

Para ampliar

Los métodos que modifican la lista en su lugar, como sort(), insert() o remove(), devuelven None; por eso la expresión lista = lista.sort() es un error frecuente (Python Software Foundation, s. f.-a).

Comprensión de listas

La comprensión de listas es una sintaxis breve para crear una lista nueva a partir de los valores de otra secuencia. Consiste en una expresión, una cláusula for y, de forma opcional, una condición if. La brevedad se logra a costa de una menor legibilidad cuando la expresión es compleja.

nueva_lista = [expresion for item in iterable if condicion]

# Caso con else: la condición se coloca antes del for
nueva_lista = [expresion if condicion else otra_expresion for item in iterable]

nueva_lista = [num**2 for num in range(10) if num < 5]
print(nueva_lista)
>> [0, 1, 4, 9, 16]

Tuplas

Una tupla almacena varios elementos en una sola variable. Es ordenada, admite duplicados y es inmutable: sus elementos no pueden reasignarse una vez creada. Esa característica la hace más eficiente en memoria y la protege de modificaciones accidentales.

mi_tupla = (1, "dos", [3.33, "cuatro"], (5.0, 6))

print(mi_tupla[3][0])    # indexado
>> 5.0

lista_1 = list(mi_tupla) # conversión (casting): ahora es mutable

a, b, c, d = mi_tupla    # desempaquetado
print(c)
>> [3.33, 'cuatro']
Para ampliar

La inmutabilidad se refiere a la tupla, no a los objetos que contiene: una tupla puede incluir una lista, y esa lista sí puede modificarse (Python Software Foundation, s. f.-a).

Diccionarios

Un diccionario almacena información en pares clave: valor. Se accede a cada valor por el nombre de su clave, no por un índice numérico. Es mutable, no admite claves repetidas y, a partir de Python 3.7, conserva el orden de inserción.

persona = {
    "nombre": "Ana",
    "edad": 25,
    "ciudad": "Quito"
}

print(persona["nombre"])
>> Ana

print(persona.get("correo", "No definido"))   # evita errores si la clave no existe
>> No definido

Las operaciones habituales son las siguientes:

persona["edad"] = 26                  # modificar
persona["profesión"] = "Ingeniera"    # agregar
del persona["ciudad"]                 # eliminar una clave
persona.pop("edad")                   # eliminar y devolver el valor

datos = {}                            # diccionario vacío
persona = dict(nombre="Luis", edad=30)

print(persona.keys())                 # dict_keys(['nombre', 'edad'])
print(persona.values())               # dict_values(['Luis', 30])

Recorrido de un diccionario

El método items() devuelve pares (clave, valor), por lo que es la forma recomendada de recorrer un diccionario. Cuando el valor es una tupla, puede desempaquetarse en el mismo for.

for clave, valor in persona.items():
    print(clave, ":", valor)

usuarios = {
    "yasmani": ("yasmani@gmail.com", "123456"),
    "juan": ("juan@gmail.com", "123456"),
}

for usuario, (correo, clave) in usuarios.items():
    print(usuario, correo, clave)
>> yasmani yasmani@gmail.com 123456
>> juan juan@gmail.com 123456
Importante

Los ejemplos con contraseñas en un diccionario son únicamente didácticos. En una aplicación real las contraseñas no se almacenan en texto plano.

Comprensión de diccionarios y unión

{clave: valor for valor in iterable if condicion}   # comprensión de diccionario

dic_a | dic_b                                        # el símbolo | une un diccionario con otro

Los diccionarios son adecuados cuando se necesita acceso rápido por clave, estructuras del tipo «nombre → valor» o registros con campos nombrados, por ejemplo un alumno con nombre, edad y nota.

Conjuntos (sets)

Un conjunto es una colección mutable de elementos inmutables, sin orden y sin elementos repetidos (Python Software Foundation, s. f.-a). Se usa para eliminar duplicados y para operaciones de teoría de conjuntos. Un conjunto vacío se crea con set(), porque {} crea un diccionario.

mi_set_a = {1, 2, "tres"}
mi_set_b = {3, "tres"}

Síntesis

  • Las listas son ordenadas y mutables; las tuplas, ordenadas e inmutables.
  • Los diccionarios asocian claves únicas con valores y se recorren con items().
  • Los conjuntos no tienen orden ni duplicados y admiten operaciones de unión, intersección y diferencia.
  • La comprensión de listas y de diccionarios crea colecciones nuevas con una sintaxis compacta.

Control de flujo

El bucle for

A diferencia de otros lenguajes, el bucle for de Python recorre los elementos de cualquier secuencia (cadenas, listas, tuplas, diccionarios, conjuntos, rangos) en el orden en que aparecen. La sintaxis es:

for item in iterable:
    # bloque de código (la indentación es obligatoria)

En cada iteración, la variable item toma el valor de un elemento del iterable y puede usarse dentro del bloque.

frutas = ["manzana", "pera", "uva"]
for fruta in frutas:
    print(fruta)

for i in range(5):            # del 0 al 4
    print(i)

for i in range(1, 10, 2):     # range(inicio, fin, paso): 1, 3, 5, 7, 9
    print(i)

colores = ["rojo", "verde", "azul"]
for i, color in enumerate(colores):   # recorre con el índice
    print(i, color)

nombres = ["Ana", "Luis"]
edades = [20, 25]
for nombre, edad in zip(nombres, edades):   # recorre varias listas a la vez
    print(f"{nombre} tiene {edad} años")

for letra in "python":                # recorre una cadena
    print(letra)

El bucle while

El bucle while se parece más a un condicional if que a un for: repite un bloque mientras la condición sea verdadera y se detiene cuando se vuelve False. La condición se evalúa antes de cada iteración. Admite una cláusula else, que se ejecuta cuando la condición pasa a ser falsa.

contador = 1
while contador <= 5:
    print("Repetición", contador)
    contador += 1
>> Repetición 1
>> ...
>> Repetición 5
Importante

Si la condición nunca se vuelve falsa, el bucle es infinito. Debe verificarse que alguna instrucción del bloque modifique las variables de la condición, como contador += 1 en el ejemplo.

Control de bucles: break, continue, pass y else

Nota. Adaptado de las notas del autor.

# break: detiene el bucle
while True:
    texto = input("Escribe algo (salir para terminar): ")
    if texto == "salir":
        break
    print("Dijiste:", texto)

# continue: salta el valor 2
for i in range(5):
    if i == 2:
        continue
    print(i)
>> 0  1  3  4

# pass: marcador de posición
def funcion():
    pass  # pendiente de implementar

# else en un bucle: se ejecuta porque no hubo break
for i in range(3):
    print(i)
else:
    print("Todo bien, sin break")

El siguiente ejemplo combina varias de estas palabras clave:

while True:
    dato = input("Escribe un número positivo: ")
    if dato == "salir":
        break
    if not dato.isdigit():
        print("Entrada no válida.")
        continue
    numero = int(dato)
    if numero == 0:
        pass  # aquí podría añadirse lógica en el futuro
    print("Número recibido:", numero)

Síntesis

  • for recorre los elementos de un iterable; while repite mientras una condición sea verdadera.
  • break, continue y pass controlan el comportamiento dentro de un bucle.
  • La cláusula else de un bucle solo se ejecuta si no hubo break.
