Manejo de archivos

Apertura, lectura y escritura

La función open(archivo, modo) abre un archivo y devuelve un objeto sobre el que pueden aplicarse métodos de lectura y escritura. El parámetro modo determina qué operaciones se permiten y qué ocurre con el contenido previo.

# Escritura (sobrescribe) y lectura
archivo = open("archivo.txt", "w")
archivo.write("hola mundo")
archivo.close()

archivo = open("archivo.txt", "r")
print(archivo.read())
archivo.close()

# Añadir contenido al final
archivo = open("archivo.txt", "a")
archivo.write("hola mundo")
archivo.close()
Para ampliar

La documentación oficial recomienda emplear la palabra clave with al trabajar con archivos: el archivo se cierra correctamente al terminar el bloque, incluso si se produce una excepción. Sin ella, una escritura puede no llegar completa al disco si no se invoca close() (Python Software Foundation, s. f.-b).

with open("./ruta/del/archivo.txt", "r", encoding="utf-8") as f:
    contenido = f.read()

El argumento encoding="utf-8" permite que Python soporte los caracteres del español, como la «ñ» y las letras con tilde. Resulta conveniente indicarlo de forma explícita para que el programa se comporte igual en distintos sistemas operativos.

Rutas con pathlib

La clase Path del módulo pathlib construye rutas de archivos y carpetas de forma independiente del sistema operativo.

from pathlib import Path

base = Path.home()                       # carpeta personal del usuario
ruta = Path(base, "Loja", "sucre.txt")
print(ruta)
>> C:\Users\usuario\Loja\sucre.txt

Compresión con zipfile

El módulo zipfile permite crear, leer, escribir y extraer archivos ZIP.

import zipfile

# Crear un archivo ZIP y agregarle un archivo existente
with zipfile.ZipFile("archivo_comprimido.zip", "w") as zipf:
    zipf.write("documento.txt")

# Extraer todo el contenido
with zipfile.ZipFile("archivo_comprimido.zip", "r") as zipf:
    zipf.extractall("carpeta_destino")

# Listar el contenido
with zipfile.ZipFile("archivo_comprimido.zip", "r") as zipf:
    print(zipf.namelist())

Con shutil, la compresión de una carpeta se reduce a una instrucción:

import shutil

shutil.copy("archivo.txt", "copia.txt")
shutil.move("archivo.txt", "carpeta_destino/archivo.txt")
shutil.copytree("carpeta_origen", "carpeta_copia")
shutil.make_archive("backup", "zip", "carpeta_a_comprimir")

Síntesis

  • El modo de apertura determina si se lee, se escribe, se añade o se crea un archivo.
  • with open(...) garantiza el cierre del archivo; conviene indicar encoding="utf-8".
  • pathlib, os y shutil gestionan rutas, carpetas, copias y compresión.

Manejo de errores y calidad del código

Excepciones: try, except, else y finally

El manejo de excepciones permite controlar situaciones inesperadas durante la ejecución, de modo que el programa no se detenga abruptamente. Sirve para que el programa no se cierre cuando el usuario comete un error (por ejemplo, al escribir letras donde se pedía un número), para mostrar un mensaje claro y para continuar de forma controlada.

try:
    # código que podría fallar
except:
    # código si falla
else:
    # código si no hubo error
finally:
    # código que siempre se ejecuta
  • try: contiene el código que se espera pueda lanzar un error.
  • except: gestiona el error; si ocurre dentro del bloque try, se interrumpe su ejecución y se ejecuta lo definido en except.
  • else: se ejecuta solo si no se lanzó ninguna excepción en el try.
  • finally: se ejecuta siempre, se haya lanzado o no una excepción.
try:
    numero = int(input("Ingrese un número: "))
except ValueError:
    print("Eso no es un número válido.")
else:
    print(f"¡Ingresaste correctamente el número {numero}!")
finally:
    print("Fin de la operación.")

Si el usuario escribe un número válido, se muestra el número y «Fin de la operación». Si escribe un texto no numérico, se muestra el aviso de error y también «Fin de la operación».

Consejo

Es preferible capturar el tipo de excepción concreto (except ValueError:) que usar un except: genérico, porque este último también oculta errores inesperados.

Sentencias assert

La sentencia assert verifica una condición durante la ejecución y, si es falsa, lanza un error con un mensaje. Su estructura es assert condición, mensaje de error. El método .isnumeric() de las cadenas devuelve True si el texto está formado por números, por lo que resulta útil para validar entradas.

entrada = "25"
assert entrada.isnumeric(), "Debe ingresarse un número"

Depuración

El depurador permite detener el programa y observar su estado. En Visual Studio Code, el procedimiento es el siguiente:

  1. Abrir la vista Ejecución y depuración y seleccionar Python file.
  2. Colocar un punto de interrupción (círculo rojo) en la línea donde debe detenerse el programa.
  3. Con el botón de pausa se detiene la ejecución en el punto deseado.
  4. Con la opción de depurar paso a paso se avanza línea por línea.
  5. Con la opción de depurar paso a paso por instrucciones se ingresa al origen del código para revisarlo.

Análisis estático con pylint

pylint es una herramienta que analiza el código Python de forma automática: busca errores de sintaxis, malas prácticas (nombres poco claros, funciones sin documentar), incumplimientos de las normas de estilo PEP 8 (nombres significativos, espacios, un máximo de 79 caracteres por línea) y código no utilizado. Además, asigna al archivo una puntuación de 0 a 10. Se instala una sola vez y luego se ejecuta sobre el archivo:

pip install pylint
pylint ejercicio_ejemplo.py

Pruebas automáticas con unittest

El módulo unittest viene incluido en Python y permite crear pruebas automáticas que comprueban el funcionamiento correcto de funciones, clases y métodos. Está inspirado en JUnit y su unidad básica es el caso de prueba, que verifica una respuesta específica ante un conjunto de entradas (Python Software Foundation, s. f.-e). El procedimiento es:

  1. Importar el módulo: import unittest.
  2. Crear una clase de prueba que herede de unittest.TestCase.
  3. Definir métodos cuyo nombre comience con test_; esa convención indica al ejecutor qué métodos son pruebas.
  4. Ejecutar las pruebas con unittest.main().
import unittest


def sumar(a, b):
    return a + b


class TestSumar(unittest.TestCase):
    def test_suma_correcta(self):
        self.assertEqual(sumar(2, 3), 5)


if __name__ == "__main__":
    unittest.main()

Al ejecutar el archivo, la salida indica OK si las pruebas pasan o señala la prueba que falló y el motivo.

Tipado y verificación con mypy

Los lenguajes de programación se clasifican según su sistema de tipos en estático, dinámico, débil y fuerte. Python es de tipado dinámico, pero desde la versión 3.6 permite anotar los tipos de las variables, lo que facilita la lectura y la detección de errores:

a: int = 5
b: str = "hola"
c: bool = True

from typing import Dict, List, Tuple

numeros: List[int] = [1, 2, 3]
persona: Dict[str, int] = {"edad": 25}
punto: Tuple[int, int] = (3, 4)

Las anotaciones no se verifican al ejecutar el programa. Para comprobarlas se utiliza mypy, un módulo que muestra en consola los errores de tipos y que se complementa con el módulo typing:

pip install mypy
mypy nombre_archivo.py --check-untyped-defs

Síntesis

  • try/except/else/finally controlan los errores en tiempo de ejecución.
  • assert, el depurador y pylint ayudan a detectar problemas durante el desarrollo.
  • unittest automatiza las pruebas y mypy verifica las anotaciones de tipos.

Módulos, paquetes y entornos virtuales

Módulos y paquetes

Un módulo es cualquier archivo .py que contiene funciones, clases o variables reutilizables. Un paquete es una carpeta que agrupa módulos y, tradicionalmente, un archivo __init__.py. Desde Python 3.3 este archivo ya no es obligatorio, aunque sigue considerándose una buena práctica. Un módulo es, en esencia, código escrito por otra persona (o por uno mismo) que ahorra tiempo y puede implementarse en otros programas.

# archivo: saludos.py
def hola(nombre):
    return f"Hola, {nombre}!"

# archivo: main.py
import saludos

print(saludos.hola("Yasmani"))

│   ├── suma.py
│   └── resta.py
└── app.py

# app.py
from calculadora.suma import sumar
print(sumar(3, 4))

Entornos virtuales con venv

Un entorno virtual es un entorno de Python aislado y ligero, con su propio conjunto de paquetes; evita conflictos entre las dependencias de distintos proyectos. Suele ubicarse en una carpeta denominada venv o .venv dentro del proyecto, no debe incluirse en el control de versiones y puede eliminarse y recrearse en cualquier momento (Python Software Foundation, s. f.-f).

python -m venv venv           # crear el entorno llamado "venv"
deactivate                    # salir del entorno virtual

Consejo

Si PowerShell muestra el error «no puede ejecutarse el script», se resuelve ejecutando primero Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned y repitiendo la activación. Para abreviar el comando de activación, puede definirse un alias, por ejemplo alias avenv=".\venv\Scripts\activate" en Git Bash.

Instalación de dependencias con pip

  1. Activar el entorno virtual.
  2. pip freeze: muestra los módulos instalados con sus versiones.
  3. pip install pandas: instala un módulo (en el ejemplo, pandas).
  4. pip freeze > requirements.txt: guarda las dependencias con sus versiones, para compartirlas, por ejemplo, en GitHub.
  5. cat requirements.txt: muestra el contenido del archivo.
  6. pip install -r requirements.txt: instala las dependencias guardadas (lo ejecuta la persona que recibe el proyecto).

Anaconda

Anaconda es una distribución especializada en ciencia de datos; no se recomienda para otros campos de desarrollo. El procedimiento básico es:

  1. Instalar Anaconda y ejecutar Anaconda Navigator.
  2. En Environments, seleccionar Create, asignar un nombre y elegir el lenguaje.

Inicio de un proyecto nuevo

La secuencia de trabajo propuesta en las notas combina Git, un entorno virtual y la verificación de tipos:

  1. Crear la carpeta del proyecto e ingresar a ella.
  2. Inicializar el repositorio: git init.
  3. Crear el entorno virtual: python -m venv venv.
  4. Crear el archivo .gitignore y escribir en él venv/.
  5. Activar el entorno virtual.
  6. Instalar las herramientas necesarias, por ejemplo pip install mypy.
  7. Crear el archivo .py y comenzar a trabajar.
  8. Ejecutar el código con python nombre_archivo.py y revisar los tipos con mypy nombre_archivo.py --check-untyped-defs.

Módulos de la biblioteca estándar

collections

El módulo collections ofrece tipos de datos especializados que amplían las colecciones estándar.

from collections import namedtuple, deque, Counter, defaultdict

# namedtuple: tupla con campos nombrados
Persona = namedtuple("Persona", ["nombre", "edad"])
p = Persona(nombre="Yasmani", edad=30)
print(p.nombre)      # Yasmani

# deque: lista optimizada para insertar y eliminar en ambos extremos
cola = deque(["a", "b", "c"])
cola.append("d")         # agrega al final
cola.appendleft("z")     # agrega al inicio
cola.pop()               # elimina del final
cola.popleft()           # elimina del inicio

# Counter: cuenta la repetición de cada elemento
contador = Counter("abracadabra")
print(contador.most_common(2))   # [('a', 5), ('b', 2)]

# defaultdict: diccionario con valor por defecto
dic = defaultdict(int)
dic["manzanas"] += 1
print(dic["peras"])      # 0 (no lanza error)

time y timeit

Para medir el tiempo de ejecución se usan las funciones time() o perf_counter() del módulo time; la segunda es más precisa en intervalos pequeños. El módulo timeit mide con gran precisión pequeños fragmentos de código al minimizar las interferencias del sistema.

import time

inicio = time.perf_counter()
time.sleep(2)                       # simula una función que tarda 2 segundos
fin = time.perf_counter()
print(f"Tiempo de ejecución: {fin - inicio:.4f} segundos")

import timeit

tiempo = timeit.timeit(stmt='"-".join(str(n) for n in range(100))', number=1000)
print(f"Tiempo de ejecución: {tiempo:.6f} segundos")

El parámetro stmt es el código que se ejecuta, escrito como cadena, y number es la cantidad de repeticiones para obtener un promedio más preciso.

El módulo re permite trabajar con expresiones regulares, que son patrones para buscar, validar o extraer texto.

import re

texto = "Mi número es 0991234567 y mi correo es ejemplo@email.com"

resultado = re.search(r"\d{10}", texto)             # buscar un número de celular
print(resultado.group())
>> 0991234567

correo_valido = re.match(r"\w+@\w+\.\w+", "ejemplo@email.com")
print(correo_valido is not None)                    # validar un formato
>> True

print(re.findall(r"\d+", texto))                    # todas las coincidencias
>> ['0991234567']

print(re.sub(r"\d{10}", "XXXXXXXXXX", texto))       # reemplazar patrones
>> Mi número es XXXXXXXXXX y mi correo es ejemplo@email.com

  • La biblioteca estándar incluye módulos para colecciones, fechas, tiempo, matemáticas y expresiones regulares.
