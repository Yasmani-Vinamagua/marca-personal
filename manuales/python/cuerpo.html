Fundamentos del lenguaje

Estructura básica de un programa

Un programa en Python es un archivo de texto con extensión .py cuyas instrucciones se ejecutan de arriba hacia abajo. Es recomendable encapsular la lógica principal en una función y ejecutarla únicamente cuando el archivo se lanza de forma directa, no cuando se importa desde otro:

def run():
    palabra = input("Escribe una palabra: ")
    print(palabra)


if __name__ == "__main__":
    run()

Python delimita los bloques mediante la indentación, que es obligatoria. La guía de estilo oficial recomienda cuatro espacios por nivel, líneas de un máximo de 79 caracteres, nombres de funciones y variables en minúscula con guiones bajos, nombres de clases en formato CapWords y constantes en mayúsculas (van Rossum et al., 2001). Por esa razón, un valor que no cambia se nombra en mayúsculas:

LIMITE = 1000
Para ampliar

La guía de estilo se denomina PEP 8 (Python Enhancement Proposal 8) y la documentación oficial del lenguaje se encuentra en docs.python.org/3 (Python Software Foundation, s. f.-c). Al ejecutar import this en la consola se muestra el «Zen de Python», un conjunto de principios de diseño del lenguaje.

Entrada de datos con input

La función input() permite que el programa reciba datos del usuario durante su ejecución. Muestra un mensaje y devuelve lo escrito.

nombre = input("Dime tu nombre: ")
print("Tu nombre es " + nombre)
>> Dime tu nombre: Yasmani
>> Tu nombre es Yasmani

Todo valor devuelto por input() es una cadena de texto, incluso si el usuario escribe números. Cuando se requiere un número, el dato debe convertirse:

edad = int(input("¿Cuántos años tienes? "))
altura = float(input("¿Cuál es tu altura en metros? "))

Para recibir varios valores en una misma línea se combina input() con el método split():

x, y = input("Introduce dos números separados por espacio: ").split()
x = int(x)
y = int(y)
print("La suma es:", x + y)

Cadenas de texto

Indexado, búsqueda y porciones

Una cadena (string) es una secuencia de caracteres. Cada carácter ocupa una posición numerada a partir de cero, y también puede numerarse desde el final con números negativos. Las cadenas son inmutables: los métodos que las «modifican» devuelven una cadena nueva.

nombre = "Yasmani"
print(nombre[0])       # primer carácter
print(len(nombre))     # número de caracteres

El método index() localiza un carácter o fragmento y devuelve su posición; admite posiciones de inicio y fin de búsqueda. El método rindex() busca de derecha a izquierda.

mi_texto = "Esta es una prueba"
print(mi_texto.index("n"))         # 9
print(mi_texto.index("a", 5))      # 10
print(mi_texto.index("a", 5, 16))  # 10
print(mi_texto.rindex("a"))        # 17

El corte (slicing) extrae porciones mediante la sintaxis cadena[inicio:fin:paso]. El índice final no se incluye, y un paso negativo recorre la cadena en sentido inverso.

Una lista es una secuencia ordenada y mutable de objetos de cualquier tipo: cadenas, números, booleanos o incluso otras listas.

print(len(lista_1))      # número de elementos

Comprensión de listas

La comprensión de listas es una sintaxis breve para crear una lista nueva a partir de los valores de otra secuencia. Consiste en una expresión, una cláusula for y, de forma opcional, una condición if. La brevedad se logra a costa de una menor legibilidad cuando la expresión es compleja.

nueva_lista = [expresion for item in iterable if condicion]

# Caso con else: la condición se coloca antes del for
nueva_lista = [expresion if condicion else otra_expresion for item in iterable]

nueva_lista = [num**2 for num in range(10) if num < 5]
print(nueva_lista)
>> [0, 1, 4, 9, 16]

Tuplas

Una tupla almacena varios elementos en una sola variable. Es ordenada, admite duplicados y es inmutable: sus elementos no pueden reasignarse una vez creada. Esa característica la hace más eficiente en memoria y la protege de modificaciones accidentales.

mi_tupla = (1, "dos", [3.33, "cuatro"], (5.0, 6))

print(mi_tupla[3][0])    # indexado
>> 5.0

lista_1 = list(mi_tupla) # conversión (casting): ahora es mutable

a, b, c, d = mi_tupla    # desempaquetado
print(c)
>> [3.33, 'cuatro']
Para ampliar

La inmutabilidad se refiere a la tupla, no a los objetos que contiene: una tupla puede incluir una lista, y esa lista sí puede modificarse (Python Software Foundation, s. f.-a).

Diccionarios

Un diccionario almacena información en pares clave: valor. Se accede a cada valor por el nombre de su clave, no por un índice numérico. Es mutable, no admite claves repetidas y, a partir de Python 3.7, conserva el orden de inserción.

persona = {
    "nombre": "Ana",
    "edad": 25,
    "ciudad": "Quito"
}

print(persona["nombre"])
>> Ana

print(persona.get("correo", "No definido"))   # evita errores si la clave no existe
>> No definido

Las operaciones habituales son las siguientes:

persona["edad"] = 26                  # modificar
persona["profesión"] = "Ingeniera"    # agregar
del persona["ciudad"]                 # eliminar una clave
persona.pop("edad")                   # eliminar y devolver el valor

datos = {}                            # diccionario vacío
persona = dict(nombre="Luis", edad=30)

print(persona.keys())                 # dict_keys(['nombre', 'edad'])
print(persona.values())               # dict_values(['Luis', 30])

Recorrido de un diccionario

El método items() devuelve pares (clave, valor), por lo que es la forma recomendada de recorrer un diccionario. Cuando el valor es una tupla, puede desempaquetarse en el mismo for.

for clave, valor in persona.items():
    print(clave, ":", valor)

usuarios = {
    "yasmani": ("yasmani@gmail.com", "123456"),
    "juan": ("juan@gmail.com", "123456"),
}

for usuario, (correo, clave) in usuarios.items():
    print(usuario, correo, clave)
>> yasmani yasmani@gmail.com 123456
>> juan juan@gmail.com 123456
Importante

Los ejemplos con contraseñas en un diccionario son únicamente didácticos. En una aplicación real las contraseñas no se almacenan en texto plano.

Comprensión de diccionarios y unión

{clave: valor for valor in iterable if condicion}   # comprensión de diccionario

Los diccionarios son adecuados cuando se necesita acceso rápido por clave, estructuras del tipo «nombre → valor» o registros con campos nombrados, por ejemplo un alumno con nombre, edad y nota.

mi_set_a = {1, 2, "tres"}
mi_set_b = {3, "tres"}

Control de flujo

El bucle for

A diferencia de otros lenguajes, el bucle for de Python recorre los elementos de cualquier secuencia (cadenas, listas, tuplas, diccionarios, conjuntos, rangos) en el orden en que aparecen. La sintaxis es:

for item in iterable:
    # bloque de código (la indentación es obligatoria)

En cada iteración, la variable item toma el valor de un elemento del iterable y puede usarse dentro del bloque.

frutas = ["manzana", "pera", "uva"]
for fruta in frutas:
    print(fruta)

for i in range(5):            # del 0 al 4
    print(i)

for i in range(1, 10, 2):     # range(inicio, fin, paso): 1, 3, 5, 7, 9
    print(i)

colores = ["rojo", "verde", "azul"]
for i, color in enumerate(colores):   # recorre con el índice
    print(i, color)

nombres = ["Ana", "Luis"]
edades = [20, 25]
for nombre, edad in zip(nombres, edades):   # recorre varias listas a la vez
    print(f"{nombre} tiene {edad} años")

for letra in "python":                # recorre una cadena
    print(letra)

El bucle while

El bucle while se parece más a un condicional if que a un for: repite un bloque mientras la condición sea verdadera y se detiene cuando se vuelve False. La condición se evalúa antes de cada iteración. Admite una cláusula else, que se ejecuta cuando la condición pasa a ser falsa.

contador = 1
while contador <= 5:
    print("Repetición", contador)
    contador += 1
>> Repetición 1
>> ...
>> Repetición 5
Importante

Si la condición nunca se vuelve falsa, el bucle es infinito. Debe verificarse que alguna instrucción del bloque modifique las variables de la condición, como contador += 1 en el ejemplo.

while True:
    dato = input("Escribe un número positivo: ")
    if dato == "salir":
        break
    if not dato.isdigit():
        print("Entrada no válida.")
        continue

    if numero == 0:

  • break, continue y pass controlan el comportamiento dentro de un bucle.
  • La cláusula else de un bucle solo se ejecuta si no hubo break.

Funciones

Definición y retorno de valores

Una función es un bloque de código con nombre que puede ejecutarse varias veces. Se define con la palabra clave def, y la instrucción return finaliza su ejecución y, opcionalmente, devuelve un valor.

def imprimir_mensaje():
    print("mensaje especial: ")
    print("estoy aprendiendo a usar funciones")


def sumar(a, b):
    return a + b


resultado = sumar(3, 4)
print(resultado)
>> 7

Argumentos de cantidad variable: *args y **kwargs

Cuando no se conoce de antemano el número de argumentos que se pasarán a una función se emplean dos sintaxis especiales. El nombre args o kwargs no es obligatorio, pero se recomienda como buena práctica; cualquier nombre precedido por * o ** cumple la misma función.

  • *args agrupa en una tupla los argumentos posicionales adicionales, después de los obligatorios.
  • **kwargs (keyword arguments) agrupa en un diccionario los argumentos con nombre, que identifican al argumento por su nombre y no por su posición.
def mi_funcion(arg_1, arg_2, *args):
    print(arg_1, arg_2, args)

mi_funcion("ejemplo", 25, 40, 75, 10)
>> ejemplo 25 (40, 75, 10)


def atributos_persona(**kwargs):
    print(kwargs)

atributos_persona(ojos="azules", pelo="corto")
>> {'ojos': 'azules', 'pelo': 'corto'}

Funciones anónimas: lambda

Una función lambda es una función sin nombre, limitada a una sola expresión. Su estructura es lambda argumentos: expresión.

doble = lambda x: x * 2
print(doble(4))
>> 8

Alcance de las variables (scope)

El alcance determina desde dónde puede utilizarse una variable. Una variable local existe solo dentro del bloque en que se define; una variable global está disponible en todas las funciones del módulo. Pueden coexistir una variable local y una global con el mismo nombre y valores distintos.

Funciones anidadas y clausuras

Una función anidada (nested function) es una función definida dentro de otra. Una clausura (closure) ocurre cuando una función interna recuerda una variable de un ámbito superior aunque ese ámbito ya no exista. Para que exista una clausura deben cumplirse tres condiciones:

  1. Debe haber una función anidada.
  2. La función anidada debe hacer referencia a un valor de un ámbito superior.
  3. La función que envuelve a la anidada debe retornarla.
def crear_multiplicador(factor):
    def multiplicar(numero):
        return numero * factor   # recuerda "factor"
    return multiplicar


por_tres = crear_multiplicador(3)
print(por_tres(5))
>> 15

Las clausuras aparecen con frecuencia en clases cortas y en el uso de decoradores.

Síntesis

  • def define una función y return devuelve un valor.
  • *args recibe argumentos posicionales como tupla; **kwargs, argumentos con nombre como diccionario.
  • Una clausura es una función interna que conserva variables del ámbito que la contiene.

Decoradores, iteradores y generadores

Decoradores

Un decorador es una función que recibe otra función como parámetro, le añade comportamiento y retorna una función diferente, sin modificar el código interno de la original. Se emplea para agregar comprobaciones (por ejemplo, permisos), medir el tiempo de ejecución, registrar eventos y reutilizar código. Se aplica escribiendo @nombre_del_decorador encima de la función decorada.

def decorar_saludo(funcion):

    def otra_funcion(palabra):
        print("hola")
        funcion(palabra)
        print("adios")

    return otra_funcion


@decorar_saludo
def minuscula(texto):
    print(texto.lower())


def mayuscula(texto):
    print(texto.upper())


mayuscula("PytHon")
minuscula("PytHon")
>> PYTHON
>> hola
>> python
>> adios
Nota

La línea @decorar_saludo equivale a ejecutar minuscula = decorar_saludo(minuscula). Si la función original recibe parámetros, la función interna del decorador debe aceptar *args y **kwargs para transmitirlos.

Iterables e iteradores

Un iterable es todo objeto que puede recorrerse en un ciclo, como una lista o una cadena. Un iterador produce sus elementos de uno en uno; ahorra recursos porque puede representar secuencias y progresiones matemáticas ocupando poca memoria.

Generadores

Un generador es una función especial que no devuelve todos los valores a la vez, sino que los genera uno por uno cuando se le piden. Utiliza la palabra clave yield en lugar de return: al encontrarla, pausa su ejecución y devuelve el valor; cuando se reanuda, continúa justo donde se quedó. Conserva un estado, ofrece las ventajas de un iterador con una sintaxis más sencilla y es útil para leer archivos línea por línea, procesar datos masivos o crear flujos infinitos.

def mi_generador():
    x = 1
    yield x

    x += 1
    yield x

    x += 1
    yield x


g = mi_generador()

print(g)
print(next(g))
print(next(g))
print("Hola mundo")
print(next(g))
>> <generator object mi_generador at 0x000001C7FF054B80>
>> 1
>> 2
>> Hola mundo
>> 3

La dirección de memoria que aparece en la primera línea varía en cada ejecución. Las expresiones generadoras siguen la sintaxis de la comprensión de listas, pero con paréntesis: mientras la comprensión de listas almacena todos los elementos en memoria, la expresión generadora los entrega uno por uno.

cuadrados_lista = [n**2 for n in range(1000)]   # todos los elementos en memoria
cuadrados_gen = (n**2 for n in range(1000))     # un elemento a la vez

Síntesis

  • Un decorador envuelve una función para ampliar su comportamiento sin alterar su código.
  • Un generador, definido con yield, produce valores bajo demanda y ahorra memoria.
  • La expresión generadora es la versión perezosa de la comprensión de listas.

Programación orientada a objetos

Clases, objetos, atributos y métodos

Una clase es una plantilla que define las propiedades (atributos) y las acciones (métodos) de los objetos creados a partir de ella. Es un concepto fundamental de la programación orientada a objetos porque permite organizar el código de forma modular y reutilizable. Un objeto (o instancia) es una entidad concreta con sus propios datos y comportamientos, creada desde una clase.

class Perro:                      # clase

    def __init__(self, raza):     # método especial que asigna el atributo "raza"
        self.raza = raza

    def ladrar(self):             # método
        print(f"{self.raza} ha ladrado")


mi_perro = Perro("Chihuahua")     # objeto con el atributo "Chihuahua"
mi_perro.ladrar()
>> Chihuahua ha ladrado

Atributos

Los atributos son las características o datos que pertenecen a un objeto o a una clase. Los atributos de instancia son propios de cada objeto y se definen con self (por ejemplo, la raza, el color o el nombre de un perro). Los atributos de clase son comunes a todos los objetos y se definen directamente dentro de la clase.

Métodos

Los métodos son funciones definidas dentro de una clase que permiten a los objetos realizar acciones con sus atributos. Existen tres tipos.

De clase@classmethodclsSe relacionan con la clase, no con las instancias; acceden a los atributos de clase.

class Pajaro:

    alas = True                       # atributo de clase

    def __init__(self, color, especie):
        self.color = color
        self.especie = especie

    def caracteristicas(self):        # método de instancia

    @classmethod
    def poner_huevos(cls, cantidad):  # método de clase
        print(f"Puso {cantidad} huevos")
        cls.alas = True               # se puede modificar un atributo de clase

Herencia

La herencia permite que una clase obtenga los atributos y métodos de otra. La clase original se denomina clase padre o superclase, y la que hereda, clase hija o subclase. La subclase dispone automáticamente de todo lo definido en la superclase y puede agregar elementos propios.

class Animal:
    def __init__(self, edad, color):
        self.edad = edad
        self.color = color

    def nacer(self):
        print("Este animal ha nacido")
        print(f"Tiene {self.edad} años y es de color {self.color}")


class Pajaro(Animal):
    pass


piolin = Pajaro(2, "amarillo")
piolin.nacer()

Herencia extendida

La subclase puede además añadir atributos o métodos propios, sobrescribir un método heredado para que funcione de otra manera y llamar al método original mediante super() cuando necesita conservar parte del comportamiento de la superclase.

class Animal:
    def __init__(self, edad, color):
        self.edad = edad
        self.color = color

    def nacer(self):
        print("Este animal ha nacido")

    def hablar(self):
        print("Este animal emite un sonido")


class Pajaro(Animal):
    def __init__(self, edad, color, vuelo_metros):
        super().__init__(edad, color)       # reutiliza el constructor de Animal
        self.vuelo_metros = vuelo_metros

    def hablar(self):                       # sobrescribe el método heredado
        print(f"{self.color}")

    def volar(self):
        print(f"El pajaro vuela {self.vuelo_metros} metros")


class Aguila(Pajaro):
    pass


mi_aguila = Aguila(30, "marrón", 5)
mi_aguila.volar()
>> El pajaro vuela 5 metros

Polimorfismo

El polimorfismo significa que diferentes clases pueden usar el mismo nombre de método, pero cada una lo implementa a su manera. Así, un mismo código puede operar sobre objetos de clases distintas.

class Vaca:
    def __init__(self, nombre):
        self.nombre = nombre

    def hablar(self):
        print(self.nombre + " dice muuuu")


class Oveja:
    def __init__(self, nombre):
        self.nombre = nombre

    def hablar(self):
        print(self.nombre + " dice meeeeee")


animales = [Vaca("Aurora"), Oveja("Nube")]

for animal in animales:
    animal.hablar()
>> Aurora dice muuuu
>> Nube dice meeeeee

Los métodos especiales (también llamados métodos «mágicos» o magic methods) son funciones cuyo nombre empieza y termina con dos guiones bajos, como __nombre__. Otorgan comportamientos particulares a los objetos y Python los invoca de forma automática en ciertas situaciones.

Manejo de errores y calidad del código

Excepciones: try, except, else y finally

El manejo de excepciones permite controlar situaciones inesperadas durante la ejecución, de modo que el programa no se detenga abruptamente. Sirve para que el programa no se cierre cuando el usuario comete un error (por ejemplo, al escribir letras donde se pedía un número), para mostrar un mensaje claro y para continuar de forma controlada.

try:
    # código que podría fallar
except:
    # código si falla
else:
    # código si no hubo error
finally:
    # código que siempre se ejecuta
  • try: contiene el código que se espera pueda lanzar un error.
  • except: gestiona el error; si ocurre dentro del bloque try, se interrumpe su ejecución y se ejecuta lo definido en except.
  • else: se ejecuta solo si no se lanzó ninguna excepción en el try.
  • finally: se ejecuta siempre, se haya lanzado o no una excepción.
try:
    numero = int(input("Ingrese un número: "))
except ValueError:
    print("Eso no es un número válido.")
else:
    print(f"¡Ingresaste correctamente el número {numero}!")
finally:
    print("Fin de la operación.")

Si el usuario escribe un número válido, se muestra el número y «Fin de la operación». Si escribe un texto no numérico, se muestra el aviso de error y también «Fin de la operación».

Consejo

Es preferible capturar el tipo de excepción concreto (except ValueError:) que usar un except: genérico, porque este último también oculta errores inesperados.

Pruebas automáticas con unittest

El módulo unittest viene incluido en Python y permite crear pruebas automáticas que comprueban el funcionamiento correcto de funciones, clases y métodos. Está inspirado en JUnit y su unidad básica es el caso de prueba, que verifica una respuesta específica ante un conjunto de entradas (Python Software Foundation, s. f.-e). El procedimiento es:

  1. Importar el módulo: import unittest.
  2. Crear una clase de prueba que herede de unittest.TestCase.
  3. Definir métodos cuyo nombre comience con test_; esa convención indica al ejecutor qué métodos son pruebas.
  4. Ejecutar las pruebas con unittest.main().
import unittest


def sumar(a, b):
    return a + b


class TestSumar(unittest.TestCase):
    def test_suma_correcta(self):
        self.assertEqual(sumar(2, 3), 5)


if __name__ == "__main__":
    unittest.main()

Al ejecutar el archivo, la salida indica OK si las pruebas pasan o señala la prueba que falló y el motivo.

time y timeit

Para medir el tiempo de ejecución se usan las funciones time() o perf_counter() del módulo time; la segunda es más precisa en intervalos pequeños. El módulo timeit mide con gran precisión pequeños fragmentos de código al minimizar las interferencias del sistema.

import time

inicio = time.perf_counter()
time.sleep(2)                       # simula una función que tarda 2 segundos
fin = time.perf_counter()
print(f"Tiempo de ejecución: {fin - inicio:.4f} segundos")

import timeit

tiempo = timeit.timeit(stmt='"-".join(str(n) for n in range(100))', number=1000)
print(f"Tiempo de ejecución: {tiempo:.6f} segundos")

El parámetro stmt es el código que se ejecuta, escrito como cadena, y number es la cantidad de repeticiones para obtener un promedio más preciso.

Paso 9. Detectar colisiones

Se calcula la distancia euclidiana entre la bala y el enemigo: si es menor que 27 píxeles, se considera que hubo colisión. En ese caso la bala vuelve a su posición inicial, aumenta el puntaje y el enemigo reaparece en un lugar aleatorio.

import math

puntaje = 0

def colision(x_1, y_1, x_2, y_2):
    operacion1 = math.pow((x_2 - x_1), 2)
    operacion2 = math.pow((y_2 - y_1), 2)
    distancia = math.sqrt(operacion1 + operacion2)
    if distancia < 27:
        return True
    else:
        return False

# Escuchar el micrófono y devolver el audio como texto
def transformar_audio_en_texto():

    # almacenar el reconocedor en una variable
    r = sr.Recognizer()

    # configurar el micrófono
    with sr.Microphone() as origen:

        # tiempo de espera
        r.pause_threshold = 0.8

        # informar que comenzó la grabación
        print("ya puedes hablar")

        # guardar lo que escuche como audio
        audio = r.listen(origen)

        try:
            # buscar en Google
            pedido = r.recognize_google(audio, language="es-ec")

            # prueba de que pudo ingresar
            print("Dijiste: " + pedido)

            # devolver pedido
            return pedido

        # en caso de que no comprenda el audio
        except sr.UnknownValueError:
            print("Ups, no entendí")
            return "sigo esperando"

        # en caso de no resolver el pedido
        except sr.RequestError:
            print("Ups, no hay servicio")
            return "sigo esperando"

        # error inesperado
        except:
            print("Ups, algo ha salido mal")
            return "sigo esperando"

Reconocimiento facial

El reconocimiento facial se apoya en cuatro componentes: opencv-python captura la imagen o el video; face-recognition (que utiliza dlib) detecta y reconoce rostros; numpy procesa los datos de imagen como matrices, y cmake se usa durante la instalación para compilar los componentes necesarios.

El ejemplo se desarrolla en ocho etapas: cargar las imágenes, comparar caras, medir la diferencia (distancia), mostrar la distancia, crear una base de datos, encontrar coincidencias, mostrar coincidencias y registrar la asistencia.

Comparación de dos fotografías

La función compare_faces() devuelve si dos rostros coinciden. Por defecto la tolerancia es de 0,6: cuanto más cercana a cero, más exacta debe ser la coincidencia. La función face_distance() mide la diferencia numérica entre los rostros.

            nombre = nombres_empleados[indice_coincidencia]

            y1, x2, y2, x1 = caraubic
            cv2.rectangle(imagen, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv2.rectangle(imagen, (x1, y2 - 35), (x2, y2), (0, 255, 0), cv2.FILLED)
            cv2.putText(imagen, nombre, (x1 + 6, y2 - 6),
                        cv2.FONT_HERSHEY_DUPLEX, 1, (255, 255, 255), 2)

            registrar_ingresos(nombre)

            # mostrar la imagen obtenida
            cv2.imshow("Imagen web", imagen)

            # mantener la ventana abierta
            cv2.waitKey(0)

Las imágenes faciales son datos personales sensibles. Un sistema real requiere el consentimiento de las personas registradas y el cumplimiento de la normativa de protección de datos vigente.

Sitio web con Django

Django es un framework web de alto nivel para Python que permite desarrollar aplicaciones web de forma rápida, segura y escalable. El procedimiento inicial es el siguiente.

  1. Crear y activar un entorno virtual (ver el capítulo 11): python -m venv venv.
  2. Instalar Django en el entorno: pip install django. Esto permite crear aplicaciones web con funcionalidades completas.
  3. Crear un directorio para el proyecto: mkdir src y cd src. El nombre src es una abreviatura habitual de «source» (código fuente).
  4. Crear el proyecto: django-admin startproject nombre_proyecto, y luego ingresar a la carpeta con cd nombre_proyecto.
  5. Iniciar el servidor de desarrollo: python manage.py runserver. El sitio queda disponible en http://127.0.0.1:8000/; aún no tiene contenido, pero el sistema funciona.
  6. Aplicar las migraciones iniciales: python manage.py migrate. Las aplicaciones internas de Django (auth, admin, sessions) requieren tablas en la base de datos; este comando las crea.
  7. Crear un usuario administrador: python manage.py createsuperuser. Ese usuario puede iniciar sesión en el panel de administración (/admin) para gestionar usuarios y modelos.

Glosario

Atributo. Dato o característica que pertenece a un objeto o a una clase.

Clase. Plantilla que define los atributos y métodos de los objetos creados a partir de ella.

Clausura (closure). Función interna que recuerda variables de un ámbito superior aunque este ya no exista.

Comprensión de listas. Sintaxis breve para crear una lista a partir de otra secuencia.

Decorador. Función que recibe otra función, le añade comportamiento y retorna una función distinta.

Diccionario. Colección de pares clave: valor, con claves únicas.

Entorno virtual. Entorno de Python aislado, con su propio conjunto de paquetes.

Excepción. Error detectado durante la ejecución que puede capturarse con try/except.

Generador. Función con yield que produce sus valores uno por uno y conserva su estado.

Herencia. Mecanismo por el que una clase obtiene los atributos y métodos de otra.

Iterable. Objeto que puede recorrerse en un ciclo, como una lista o una cadena.

Método. Función definida dentro de una clase.

Módulo. Archivo .py con código reutilizable.

Objeto (instancia). Entidad concreta creada a partir de una clase.

Paquete. Carpeta que agrupa módulos.

Polimorfismo. Capacidad de clases distintas de responder al mismo método de maneras diferentes.

Tupla. Secuencia ordenada e inmutable de elementos.

El siguiente programa reúne todos los pasos del proyecto «Invasión Espacial» (capítulo 12) en su versión final.

import pygame
import random
import math
from pygame import mixer
import sys
import os


# Función para manejar rutas en modo script o ejecutable
def ruta_absoluta(ruta_relativa):
    base_path = getattr(sys, "_MEIPASS", os.path.dirname(os.path.abspath(__file__)))
    return os.path.join(base_path, ruta_relativa)


pygame.init()

pantalla = pygame.display.set_mode((800, 600))

# Título e icono
icono = pygame.image.load(ruta_absoluta("logo_color.png"))
pygame.display.set_caption("Invasión Lolera")
pygame.display.set_icon(icono)

# Agregar música
mixer.music.load(ruta_absoluta("MusicaFondo.mp3"))
mixer.music.set_volume(0.5)
mixer.music.play(-1)

# Jugador
img_jugador = pygame.image.load(ruta_absoluta("mouse.png"))
jugador_x = 368
jugador_y = 500
jugador_x_cambio = 0

# Enemigos
img_enemigo = []
enemigo_x = []
enemigo_y = []
enemigo_x_cambio = []
enemigo_y_cambio = []
cantidad_enemigos = 7

for e in range(cantidad_enemigos):
    img_enemigo.append(pygame.image.load(ruta_absoluta("veneno.png")))
    enemigo_x.append(random.randint(0, 736))
    enemigo_y.append(random.randint(50, 200))
    enemigo_x_cambio.append(1)
    enemigo_y_cambio.append(50)

# Balas
balas = []
img_bala = pygame.image.load(ruta_absoluta("bala.png"))
bala_x = 0
bala_y = 500
bala_x_cambio = 1.5
bala_y_cambio = 1.5
bala_visible = False

# Puntaje
puntaje = 0
fuente = pygame.font.Font(ruta_absoluta("freesansbold.ttf"), 32)
texto_x = 10
texto_y = 10

# Texto final del juego
fuente_final = pygame.font.Font(ruta_absoluta("freesansbold.ttf"), 40)


def texto_final():
    mi_fuente_final = fuente_final.render("GAME OVER", True, (255, 255, 255))
    pantalla.blit(mi_fuente_final, (280, 250))


def mostrar_puntaje(x, y):
    texto = fuente.render(f"Puntaje: {puntaje}", True, (255, 255, 255))
    pantalla.blit(texto, (x, y))


def jugador(x, y):
    pantalla.blit(img_jugador, (x, y))


def enemigo(x, y, ene):
    pantalla.blit(img_enemigo[ene], (x, y))


def disparar_bala(x, y):
    global bala_visible
    bala_visible = True
    pantalla.blit(img_bala, (x + 22, y + 10))


fondo = pygame.image.load(ruta_absoluta("fondo.png"))


def colision(x_1, y_1, x_2, y_2):
    distancia = math.sqrt((x_2 - x_1) ** 2 + (y_2 - y_1) ** 2)
    return distancia < 27


# Bucle del juego
se_ejecuta = True

while se_ejecuta:
    pantalla.blit(fondo, (0, 0))

    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:
            se_ejecuta = False

        if evento.type == pygame.KEYDOWN:
            if evento.key == pygame.K_LEFT:
                jugador_x_cambio = -0.8
            elif evento.key == pygame.K_RIGHT:
                jugador_x_cambio = 0.8
            elif evento.key == pygame.K_SPACE:
                sonido_bala = mixer.Sound(ruta_absoluta("disparo.mp3"))
                sonido_bala.play()
                nueva_bala = {"x": jugador_x, "y": jugador_y, "velocidad": -2}
                balas.append(nueva_bala)

        if evento.type == pygame.KEYUP:
            if evento.key in [pygame.K_LEFT, pygame.K_RIGHT]:
                jugador_x_cambio = 0

    jugador_x += jugador_x_cambio

    if jugador_x < 0:
        jugador_x = 0
    elif jugador_x > 736:
        jugador_x = 736

    for e in range(cantidad_enemigos):
        if enemigo_y[e] > 440:
            for k in range(cantidad_enemigos):
                enemigo_y[k] = 1000
            texto_final()
            break

        enemigo_x[e] += enemigo_x_cambio[e]

        if enemigo_x[e] < 0:
            enemigo_x_cambio[e] = 1
            enemigo_y[e] += enemigo_y_cambio[e]
        elif enemigo_x[e] > 736:
            enemigo_x_cambio[e] = -1
            enemigo_y[e] += enemigo_y_cambio[e]

        for bala in balas:
            if colision(enemigo_x[e], enemigo_y[e], bala["x"], bala["y"]):
                sonido_choque = mixer.Sound(ruta_absoluta("Golpe.mp3"))
                sonido_choque.play()
                balas.remove(bala)
                puntaje += 1
                enemigo_x[e] = random.randint(0, 736)
                enemigo_y[e] = random.randint(50, 200)
                break

        enemigo(enemigo_x[e], enemigo_y[e], e)

    for bala in balas[:]:
        bala["y"] += bala["velocidad"]
        pantalla.blit(img_bala, (bala["x"] + 22, bala["y"] + 10))
        if bala["y"] < 0:
            balas.remove(bala)

    jugador(jugador_x, jugador_y)
    mostrar_puntaje(texto_x, texto_y)
    pygame.display.update()
